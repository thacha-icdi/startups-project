# Startups Business Project

A practical web platform for startup learning and market validation.

## Project structure

- **888399 — Proof of Business Concept (3 credits)**  
  Market research, survey, validation, pain point, solution, Business Model Canvas, and digital tools.
- **888498 — Prototyping (3 credits)**  
  Product, process, business prototype, mock-up, and prototype testing.
- **888499 — Business Test Run (3 credits)**  
  Business test run, customer testing, customer feedback, results, improvement, and future plan.

## Version 0.1

The first version provides a responsive landing page and interactive project workspaces for the three startup projects.

## Run locally

Open `index.html` in a browser.

## Next development

The next versions will turn each workspace into practical tools for collecting startup evidence and producing project outputs.
